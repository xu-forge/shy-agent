# Brainstorm — project-workspaces-ui

背景：用户提供四张设计图，要求改版 shy UI，并新增「项目」概念。

- 图一：主题色板（主色绿 `#4ADE80`、背景 `#F8FAFC`、辅色蓝/紫、中性 slate、64px 图标轨、8px 网格、卡片 16px 圆角）
- 图二：会话界面；用户不要右侧「工具」列表，改成会话产物；后收敛为两个 tab：会话详情、浏览器
- 图三：代码模式（新）— 文件树 | Monaco 文件内容 | 右侧会话
- 图四：素材管理（新）— 主区素材网格 | 右侧会话；会话产出的文件就是素材
- 代码 / 素材属于项目；添加时选类型即可

现有代码对照：

- 布局：宽 Sidebar（会话列表）+ ChatWorkspace + InspectorPanel（任务 / 文件 diff / 浏览器）
- 主题：MiniMax 蓝 `#0094fc`（`tokens.css`）
- 无项目实体；会话工作区固定 `~/.shy/sessions/{id}/workspace`（`getSessionWorkspace`）
- 已有 `session_files` / `session_diffs` / 内嵌浏览器

决议链（已与用户收敛）：

- Q1 项目 vs 日常对话？→ 起初选「项目是会话容器、日常对话独立」；随后修订为：**所有会话都挂在项目下**；未绑定项目的会话归虚拟分组 **「未选择项目」**（`projectId = null`）。
- Q2 代码项目目录？→ **打开本机已有文件夹**（像 Cursor），跨会话共享；Agent 直接在该目录读写。
- Q3 素材库存在哪？→ **同样选本机文件夹**；网格就是该目录的视图；会话写入的文件自动成为素材卡片。
- Q4 全局导航？→ **64px 图标轨 + 可展开二级侧栏**。二级栏按项目分组列会话（含「未选择项目」）。进入代码项目后二级栏变成文件树；同项目会话用右侧聊天头下拉切换。点图标轨「项目」从文件树回到分组列表。技能 / 日历 / 设置仍走图标轨。
- Q5 代码编辑器深度？→ **Monaco**：语法高亮、可编辑、保存回磁盘；Agent 改了当前打开的文件则刷新 tab。
- Q6 普通对话右侧？→ **两个 tab：会话详情、浏览器**。详情内含元数据 + 本会话产物文件。任务清单与 diff tab 从普通对话右侧拿掉；diff 只在代码编辑器语境下看。
- Q7 落地路径？→ **方案 1 项目一等公民**：SQLite 持久化 + 打开本机目录 + Monaco + 素材网格 + 主题/导航一次改。
- Q8 创建入口？→ **不是先单独添加项目**。新建会话的输入框左下角有项目选择器：可选已有项目、可添加新项目（类型 + 选文件夹），**默认不选**。
- Q9 何时绑定并切布局？→ **发出第一条消息才写入 `projectId` 并切换布局**。发送前仍可改或清空。发出后选择器锁定（本期不支持中途换项目）。空会话始终是普通对话页。
- Q10 删项目？→ 只解绑：项目记录删除，其下会话 `projectId` 置空，回到「未选择项目」；不删磁盘文件、不删会话消息。
- Q11 在线修图/剪辑？→ **本期不做**，但素材侧必须按可插编辑器留口：`MaterialItem` + 查看器壳 + `MaterialEditor` 注册表（v1 空表）。编辑结果将来写成新文件（`derivedFrom`），不改三栏布局。

范围锁定：

**做**：图一主题（深色模式保留为衍生色）；图标轨 + 二级侧栏；项目表 + 会话 `projectId`；composer 项目选择 / 新建项目；首条消息绑定并切布局；代码工作区（文件树 + Monaco）；素材工作区（网格 + 查看器插槽 + 导入文件）；未选择项目右侧 = 详情（含产物）+ 浏览器。

**不做**：在线修图/剪辑实现、中途换项目、改项目类型、git 集成、一个文件夹挂多个项目、删项目时删磁盘文件、任务 tab 留在普通对话右侧。

验收锚点：

1. 浅色主题主色为 `#4ADE80`，背景 `#F8FAFC`；深色模式仍可切换。
2. 左缘 64px 图标轨；二级栏按「未选择项目 / 具名项目」分组会话。
3. 空会话 composer 左下角可选项目或新建（类型+文件夹），默认不选；发第一条消息前不切布局。
4. 绑定代码项目后：文件树 + Monaco + 右侧会话；Agent 相对路径写到 `rootPath`。
5. 绑定素材项目后：网格列出 `rootPath` 文件；会话新写的文件出现在网格；点卡片打开查看器壳（非编辑器）。
6. 未选择项目的右侧仅「会话详情 / 浏览器」两 tab；详情列出本会话产物。
7. 删除项目后会话仍在，归入「未选择项目」，磁盘目录仍在。
8. `npm run typecheck && npm test` 通过。
