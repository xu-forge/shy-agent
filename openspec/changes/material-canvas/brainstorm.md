# Brainstorm: material-canvas

2026-08-28 口头 brainstorm 收敛快照（对话记录，规格见 specs/）。

## 用户诉求

素材项目主区不再用文字卡片网格，改为「画布」：直接渲染图片预览、视频、文档等。

## 已决分叉

| 分叉 | 决定 |
|---|---|
| 画布形态 | 自动布局画廊（非自由拖拽摆放） |
| 持久化 | 视口位置/缩放 + 排序偏好（per project，`~/.shy`） |
| 渲染深度 | 缩略 + 点开：画布显缩略图/首帧/封面卡，点击进 lightbox |
| 素材量级 | 上千个 → 视口虚拟化必须 |
| 排序 | 修改时间倒序（Agent 新产出自动在最前） |
| 缩略图 | 主进程磁盘缓存（`~/.shy/cache/thumbs`），拒绝原图直载 |
| 视频首帧 | Chromium 内置解码截帧（零新依赖），失败降级图标卡；拒绝引入 ffmpeg |
| 画布底座 | 自研 DOM 画布（CSS transform + 虚拟化），拒绝 react-flow / konva |
| 音频 | 画布图标卡（名称+时长），点开 lightbox 播放 |

## 范围

- **In**：画布画廊、虚拟化、缩略图缓存、lightbox、视口+偏好持久化、类型过滤保留
- **Out**：手动拖拽摆放/位置持久化、素材编辑、ffmpeg 依赖、多选框选/右键菜单（后续 change）

## 验收锚点

1. 上千素材项目：打开与滚动/缩放流畅，仅视口±缓冲的节点挂载 DOM
2. 图片缩略图、视频首帧二次加载毫秒级（走磁盘缓存）
3. 无法解码的格式降级为图标卡，不白屏不崩溃
4. 点击卡片打开 lightbox：图片大图 / 视频播放 / 音频播放 / PDF、md、txt 阅读 / 其他「用系统打开」；Esc 返回画布
5. 重启或切回项目后视口与排序偏好还原
6. 过滤 chips 与导入行为在画布下正常工作
