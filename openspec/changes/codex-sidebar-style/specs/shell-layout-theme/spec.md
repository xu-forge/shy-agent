## MODIFIED Requirements

### Requirement: 单列导航与分组会话历史
主壳 MUST 提供最左侧单列导航栏（非图标轨旁再开一列会话栏），并 MUST 支持整栏展开/收起。展开时该导航栏 MUST 展示 Codex 风格短导航（「新对话」「已安排」「技能」）、分区「项目」下按未绑定组与具名项目分组的会话历史，以及分区「最近」下的跨项目最近会话；MUST NOT 展示应用名品牌标题。收起时 MUST NOT 展示会话历史与「最近」。代码项目的文件树 MUST 放在代码主区内，MUST NOT 占用导航栏。

#### Scenario: 分组
- **WHEN** 存在一条未绑定会话和一条已绑定到「后端」项目的会话
- **THEN** 展开的导航栏 MUST 在未绑定分组下列出前者，在「后端」项目下列出后者

#### Scenario: 收起不展示会话历史
- **WHEN** 用户收起导航栏
- **THEN** 界面 MUST NOT 展示会话历史列表与「最近」列表

#### Scenario: 项目分组可折叠
- **WHEN** 用户点击展开导航里某个项目分组标题行
- **THEN** 该分组下的会话列表 MUST 展开或收起，其它分组不受影响

#### Scenario: 无品牌标题
- **WHEN** 导航栏处于展开态
- **THEN** MUST NOT 显示独立的「shy」应用名品牌标题
