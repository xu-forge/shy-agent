# Brainstorm: codex-sidebar-style

## Background

用户提供 Codex 桌面端左侧栏截图，要求 shy 左侧样式对齐。此前工作 OS PRD 已撤回；本次只做侧栏视觉与项目区交互复刻，不改主区 / Agent / 项目绑定契约。

## Decision chain

### Q1：范围
- **A 视觉对齐（选定）**：短导航 + 项目树观感 + 最近区；无能力不画空壳
- B 交互也照抄（置顶/归档等）
- C 像素级含拉取请求占位

### Q2：品牌标题
- 用户明确：**不要「shy ⌄」**，导航栏不展示应用名标题
- 底栏账户卡可保留连接状态（未要求去掉）

### Q3：重点
- 用户强调：**项目那块样式要好好复刻**（文件夹图标、缩进会话、选中圆角灰底、`⋯` 菜单与交互）

## Capability mapping (agreed)

| Codex | shy |
|-------|-----|
| 新对话 | 新建会话，文案改「新对话」 |
| 已安排 | 定时任务 |
| 技能 | 技能（不画插件市场） |
| 项目 + 子会话 | 现有项目分组 + 会话 |
| 项目 `⋯` | 仅「移除项目」（无重命名 IPC，不做编辑空项） |
| 最近 | 现有会话按 updatedAt 取最近 N 条 |
| 拉取请求 / 工作树 / 置顶 / 归档 / 搜索铃 | 不做 |

## Design sketch (approved direction)

```
[ ▤ 收起 ]

  ✎ 新对话
  ⏱ 已安排
  ≡ 技能

  项目
  📁 <project>
      <session…>
  （未绑定组：无文件夹图标，文案可仍为「未选择项目」）

  最近
  <recent session titles…>

  ────────
  [s] 连接状态  ⚙
```

## Trade-offs

- 「最近」与项目下会话可能重复出现 → 接受（Codex 亦如此）；点击均打开同一会话
- 无项目重命名 → `⋯` 只有移除，避免空菜单项
- 暗色主题用 token，不硬编码 Codex 浅灰

## Out of scope

工作 OS 壳、`activeProjectId`、拉取请求、永久工作树、通知铃、顶栏前进后退
