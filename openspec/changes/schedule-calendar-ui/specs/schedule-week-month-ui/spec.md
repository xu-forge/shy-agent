## ADDED Requirements

### Requirement: 周月视图切换
定时任务主视图 MUST 提供「周」与「月」分段切换。切换 MUST 改变可见日期范围并重新加载该范围内的展开实例。默认视图可为「月」或「周」（实现选定一种并在 tasks 写明）；用户切换后在会话内 MUST 保持选择直至离开页面（不必跨启动持久化）。

#### Scenario: 切到周
- **WHEN** 用户选择「周」
- **THEN** 主区 MUST 展示当前周的七列（周一至周日），且仅加载该周范围内的实例

#### Scenario: 切到月
- **WHEN** 用户选择「月」
- **THEN** 主区 MUST 展示月网格，且加载覆盖该网格首尾日期的展开实例

---

### Requirement: 周视图列与卡片
周视图 MUST 以周一为周起始，展示七列；每列 MUST 显示星期标签与日期数字。当天所在列 MUST 有可见高亮（背景或等价）。每个展开实例 MUST 以卡片展示：本地时间 `HH:mm`、固定「本地」徽章、任务标题（可截断）、状态文案（待执行 / 已暂停 / 已过期）。

#### Scenario: 当天高亮
- **WHEN** 可见周包含今天
- **THEN** 今天对应列 MUST 呈现与其他列可区分的高亮样式

#### Scenario: 卡片内容
- **WHEN** 某日有一条 `at` 为 09:00 的启用中且未过期实例
- **THEN** 该列 MUST 出现含「09:00」「本地」、标题与「待执行」的卡片

---

### Requirement: 月视图网格与短条
月视图 MUST 以周一为周起始构建网格（含上月末/下月初溢出日）。溢出日日期数字 MUST 使用弱化样式。每个实例 MUST 以格内短条展示，格式为 `HH:mm` + 空格 + 标题摘要（可截断）。今天所在日格 MUST 有可见高亮。

#### Scenario: 周一起算
- **WHEN** 某月 1 日为周三
- **THEN** 网格第一行 MUST 以周一（上月日期）开头，且 1 日落在该行第三列（周三）

#### Scenario: 短条
- **WHEN** 某日格有实例
- **THEN** 日格内 MUST 显示以时间开头的短条文案

---

### Requirement: 实例详情弹层
用户点击周卡片或月短条（某一展开实例）时，系统 MUST 打开只读详情弹层，至少展示：标题、「本地」标识、状态、频率人话、该次预计执行时间（来自 occurrence `at`）、动作摘要（提醒文案或技能名/id）。弹层 MUST 提供关闭控件，以及「查看定时任务」操作以打开该系列的现有编辑表单。弹层 MUST NOT 提供「暂停执行此次任务」按钮（本期无单次跳过能力）。

#### Scenario: 打开详情
- **WHEN** 用户点击某条展开实例
- **THEN** MUST 出现详情弹层且预计时间对应该实例的 `at`

#### Scenario: 查看系列
- **WHEN** 用户在详情中选择「查看定时任务」
- **THEN** 系统 MUST 打开该 `taskId` 的现有编辑表单

#### Scenario: 无单次暂停
- **WHEN** 详情弹层打开
- **THEN** UI MUST NOT 展示「暂停执行此次任务」操作

---

### Requirement: 状态与频率文案
系统 MUST 用纯函数从任务 `enabled` 与实例 `at`（相对当前时间）得出状态：未启用 → 已暂停；`at` 早于现在 → 已过期；否则 → 待执行。频率人话 MUST 由 `WorkflowSchedule` 生成可读中文（至少覆盖 daily / weekdays / weekly / monthly / hourly 中产品已支持的 frequency）。

#### Scenario: 已暂停
- **WHEN** 任务 `enabled` 为 false
- **THEN** 卡片与详情状态 MUST 为「已暂停」

#### Scenario: 每天频率
- **WHEN** 调度为每天 09:00
- **THEN** 详情频率文案 MUST 包含「每天」与「09:00」

---

### Requirement: 新建与导航控件
主区 MUST 提供「新建」入口与日历导航（上一周/月、下一周/月、「今天」）。点击空白日期（月格空白或周列空白约定区域）MUST 仍可打开新建表单且默认调度对齐该日。拖拽改系列落点若保留，MUST 仍只改系列调度并提示非「仅此一次」。

#### Scenario: 今天
- **WHEN** 用户点击「今天」
- **THEN** 可见范围 MUST 跳到包含今天的周或月（取决于当前 viewMode）
