# Brainstorm: schedule-calendar-ui

## Background

用户提供三张参考图：图一按周、图二按月、图三点击实例后的任务详情弹层。shy 已有 `CalendarView` 月网格 + `ScheduleEditor` 编辑表单，无周视图、无「单次实例」只读详情、视觉与参考差距大。

侧栏 Codex 风格已落地；本次只改「已安排 / 定时任务」主区展示。

## Decision chain

### Q1：范围
- **A（选定）**：周 + 月展示样式 + 实例详情弹层；新建/编辑仍用现有表单
- B：A + 页头「自动化」文案，隐藏触发/模板 Tab
- C：连触发任务、模板、任务管理空壳一起做 → 拒绝（无能力）

用户确认「开 change」即按 A。

### Q2：页头
- 默认仍用「定时任务」作主标题；副文案可对齐参考语气（本机自动执行）
- 不增加「触发任务 / 定时任务模板 / 任务管理」入口

### Q3：详情弹层动作
- 「查看定时任务」→ 打开现有 `ScheduleEditor`（按 taskId）
- 「暂停执行此次任务」→ **首版不做**（无单次 skip IPC）；不画空按钮，避免误导
- 「本地」徽章固定展示（全是本机调度）

### Q4：状态文案
- 粗分：`enabled === false` → 已暂停；`at` 已过 → 已过期；否则 → 待执行
- 无运行历史则不做「执行中 / 已完成」

## Agreed UI

```
页头：定时任务 + 副文案 +「+ 新建」
工具栏：日期范围/月份 · ‹ › · 今天 · [周|月]
周：7 列卡片（时间 · 本地 · 标题 · 状态）
月：格内短条「HH:mm 标题…」
点实例 → 详情 Modal；点空日 → 新建表单（保留）
```

## Out of scope

触发任务、模板、任务管理、单次暂停/跳过 IPC、改侧栏导航结构、调度器语义变更
