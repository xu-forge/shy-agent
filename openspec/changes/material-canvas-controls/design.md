# Design: material-canvas-controls

## Context

`MaterialCanvas` 当前通过 `viewport` 控制世界坐标和缩放，空白区域左键拖拽平移，Ctrl/Cmd+滚轮缩放。素材卡片和分组组件尚无统一的多选状态。

## Goals / Non-Goals

**Goals:**

- 底部工具栏在桌面和移动窗口均可用，不遮挡主要内容。
- 提供缩小、缩放比例、放大、适应画布、100% 和移动/选择模式。
- 框选卡片后显示选中态；Shift 可追加选择；点击空白取消选择。
- 选择模式下拖拽空白区域绘制选择框，移动模式保留现有平移行为。

**Non-Goals:**

- 本 change 不实现批量移动、删除、导出或拖入分组。
- 不改变素材和分组的持久化模型。
- 不替换现有画布缩放算法。

## Decisions

### D1：工具栏固定在画布底部

- **选择**：工具栏使用绝对定位，位于画布底部中央，带背景、边框和阴影；画布内容保留底部安全间距。
- **理由**：控件稳定可见，又不占用画布布局空间。

### D2：缩放操作以视口中心为锚点

- **选择**：按钮缩放以视口中心为锚点；显示当前百分比；限制沿用 `CANVAS_MIN_SCALE` 和 `CANVAS_MAX_SCALE`。
- **理由**：按钮操作没有指针位置，中心锚点最可预测。

### D3：适应画布范围

- **选择**：根据内容包围盒和容器尺寸计算 scale 与 x/y，使所有根卡片、分组边界和嵌套内容完整可见，并保留边距；空画布恢复默认视图。
- **理由**：用户需要一次操作查看当前全部素材，而不是只重置比例。

### D4：显式交互模式

- **选择**：`interactionMode: 'pan' | 'select'`，默认 `pan`。移动模式沿用当前空白拖拽平移；选择模式空白拖拽绘制选择框。
- **理由**：避免同时解释“拖拽到底是平移还是框选”的歧义。

### D5：选择模型

- **选择**：以素材卡片 id 为选择单位；框选使用卡片世界坐标与选择矩形相交判定；普通框选替换选择，Shift 框选追加，点击空白清空。
- **理由**：第一期只需支持卡片级操作，分组边框不是可操作选择目标。

### D6：模式切换与快捷键

- **选择**：工具栏按钮可切换模式；Escape 取消当前框选并回到 pan；保留 Ctrl/Cmd+滚轮缩放；不新增全局快捷键。
- **理由**：减少与编辑器、系统快捷键的冲突。

## Risks / Trade-offs

- [Risk] 画布缩放后选择框坐标换算错误 → Mitigation: 统一通过 viewport 做 screen/world 转换并补不同 scale 测试。
- [Risk] 底部工具栏遮挡素材 → Mitigation: 增加底部安全间距，工具栏本身不参与画布拖拽。
- [Risk] 嵌套分组边界与卡片位置不一致 → Mitigation: 复用 `PlacedMaterial` 的绝对世界坐标，不从 DOM 反推。
- [Trade-off] 不做批量动作 → 接受，先完成可发现的查看与选择能力。

## Migration Plan

1. 增加选择状态和交互模式类型，保持默认 pan 行为不变。
2. 增加画布内容包围盒与适应画布计算。
3. 加入底部工具栏和缩放/恢复按钮。
4. 加入选择框、选中高亮和取消/追加逻辑。
5. 补充桌面、窄窗口和不同缩放比例下的测试。

## Open Questions

- 无。批量移动、删除和分组操作留到后续 change。
