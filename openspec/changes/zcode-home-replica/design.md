# Design: zcode-home-replica

## 视觉基准（按截图测量）

- 左栏：宽 220px，白底 `#fff`，右侧 1px 分隔线 `#eceef1`。
- 主区：浅灰底 `#f7f8fa`，内容列居中，最大宽 ~720px。
- 问候语：~26px / 600，深灰 `#1f2328`，左对齐于内容列。
- Composer 卡：白底、圆角 16px、1px 边框 `#e4e7ec` + 轻阴影；内边距 12-14px；输入区无边框多行；底部行高 32px。
- 「完全访问」按钮：橙色（`#ff8a00` 系）描边、勾选态实心；绑定 `autoApproveTools`。
- 模型徽标：只读 chip，显示 `ModelSettings.model`。
- 发送键：32px 圆形，深色 `#1f2328`，禁用态灰。
- 示例列表：每条一行、左侧细图标、14px 次要色，hover 浅灰。

## 布局与取舍

- 左栏导航映射（图二 → shy）：
  - 「新建任务」→ `onNewSession`
  - 「自动化」→ 定时任务（calendar 视图）
  - 「插件市场」→ 技能（skills 视图）
  - 「搜索」「插件市场原位」等无功能项：不渲染
- 「分组 | 项目」tab：结构保留；项目 tab = 会话列表（图标 + 标题 + `timeAgo`），分组 tab = 空态「还没有分组」。
- 「任务」区：显示当前会话 checklist 为空时的「还没有任务」占位（数据来自 session detail；空会话即空态）。
- 主区空态：问候语按时段（<6 凌晨好 / <12 上午好 / <18 下午好 / 否则晚上好，深夜 23-5 加「夜深啦，别忘了照顾好自己哦」式关怀文案）。
- composer 卡无顶行（项目/环境选择器隐藏）；`/` 斜杠菜单、`@` 不实现（placeholder 文案保留「使用 / 选择命令或能力」，去掉 @ 描述——shy 无 @ 上下文功能）。

## 不做

- 项目/分组数据模型、搜索、环境/质量选择、闲时任务卡片、功能推广卡片（均无后端，隐藏）。
- 线程视图、浏览器面板、InspectorPanel、设置弹窗的改动。

## 测试策略

- 渲染层无既有快照测试约束；主靠 typecheck + 既有测试回归 + 手动走查（人工）。
