## ADDED Requirements

### Requirement: Codex 风格导航骨架
渲染层 MUST 提供左侧窄栏导航，包含「聊天」「记忆」「技能」三个入口，主视觉区域留给对话工作区，整体交互 MUST 对齐 Codex 式对话优先布局（克制、少仪表盘元素）。

#### Scenario: 导航可见
- **WHEN** 用户打开应用主窗口
- **THEN** 界面 MUST 显示聊天、记忆、技能三个导航项，且主区以对话工作区为主

#### Scenario: 业务未就绪标识
- **WHEN** 用户点击记忆或技能导航（在对应能力未实现前）
- **THEN** 界面 MUST 显示克制占位说明（例如「后续版本」），MUST NOT 假装已提供完整业务功能

---

### Requirement: 就绪态与空对话轮廓
应用默认视图 MUST 展示就绪/欢迎说明，并呈现空对话区轮廓（含可见但不可发送的输入区），以提示后续对话交互形态。

#### Scenario: 默认着陆页
- **WHEN** 应用首次打开主窗口
- **THEN** 主内容区 MUST 显示就绪说明、空对话轮廓与输入区外观，且 my-agent（或应用名）标识可见

#### Scenario: 输入区未接通
- **WHEN** 用户在壳阶段尝试通过输入区发送消息
- **THEN** 系统 MUST NOT 发起真实模型请求（可忽略输入、禁用发送或提示尚未接通）

---

### Requirement: 模式切换占位
界面 MUST 提供「交互式」与「目标」模式的切换外观占位，本阶段 MUST NOT 切换真实执行引擎。

#### Scenario: 模式控件可见但非功能
- **WHEN** 用户查看对话工作区附近的模式控件
- **THEN** 控件 MUST 可见（或等价入口），且 MUST NOT 启动目标模式真实执行逻辑

---

### Requirement: 中文界面文案
壳阶段 UI 文案 MUST 使用简体中文（专有名词可保留英文）。

#### Scenario: 主要文案语言
- **WHEN** 用户查看导航、就绪说明与占位文案
- **THEN** 主要说明文字 MUST 为简体中文
