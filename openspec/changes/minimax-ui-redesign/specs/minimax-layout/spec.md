## ADDED Requirements

### Requirement: 左栏主导航
系统 MUST 在左栏顶部提供「新对话」「技能」「日历」导航，无独立的「新建任务」按钮与搜索框；底部提供设置入口（含会话列表）。

#### Scenario: 新对话
- **WHEN** 用户点击「新对话」
- **THEN** 系统 MUST 新建一个交互式会话并进入对话视图

#### Scenario: 主导航切换
- **WHEN** 用户点击「技能」或「日历」
- **THEN** 系统 MUST 切换到对应视图

### Requirement: 会话列表
系统 MUST 在左栏展示会话列表，含标题、模式与更新时间；空时给出友好提示；无搜索框，直接展示全部会话。

#### Scenario: 选择会话
- **WHEN** 用户点击某会话
- **THEN** 系统 MUST 进入对话视图并加载该会话

### Requirement: 设置入口与设置弹窗
系统 MUST 在左栏底部提供设置入口；hover 时给出设置选项；点击打开设置弹窗，弹窗左侧为 tab（记忆 / 常规设置 / 运行日志）。

#### Scenario: hover 显示选项
- **WHEN** 用户悬停设置入口
- **THEN** 系统 MUST 弹出 记忆 / 常规设置 / 运行日志 选项

#### Scenario: 打开设置弹窗
- **WHEN** 用户点击设置入口或某一选项
- **THEN** 系统 MUST 打开设置弹窗，并高亮对应左侧 tab，展示该 tab 内容

#### Scenario: 关闭弹窗
- **WHEN** 用户按下 Esc 或点击遮罩/关闭按钮
- **THEN** 系统 MUST 关闭设置弹窗

### Requirement: 空态主页
当会话无消息时，主区 MUST 以「居中 logo + 标语 + 大输入框 + 选项行 + 功能胶囊」的空态呈现。

#### Scenario: 空态发送
- **WHEN** 用户在空态输入框输入并发送
- **THEN** 系统 MUST 发送消息并进入对话线程视图

### Requirement: 对话线程与产出卡片
对话线程 MUST 渲染用户/助手/工具/系统消息；工具调用显示卡片；会话有文件写入时显示「已编辑文件」产出卡。

#### Scenario: 工具调用渲染
- **WHEN** 会话产生 `tool` 事件
- **THEN** 系统 MUST 以工具卡片展示工具名与输入

#### Scenario: 产出文件汇总
- **WHEN** 加载会话且存在 `write` 类文件记录
- **THEN** 系统 MUST 在产出区展示「已编辑 N 个文件」摘要；无记录时显示空态占位

### Requirement: 右侧环境面板
对话存在时，右侧 MUST 以单个「环境」面板呈现，含任务进度 / 已编辑文件 / 记忆 / 技能摘要；空态（无消息）时不显示右侧面板。

#### Scenario: 空态不显示面板
- **WHEN** 当前会话无任何消息
- **THEN** 系统 MUST 隐藏右侧环境面板

#### Scenario: 展示环境面板
- **WHEN** 会话已有消息
- **THEN** 系统 MUST 在右侧展示「环境」面板，含任务进度条、已编辑文件、记忆与技能摘要；空数据时给出友好提示

### Requirement: 展示型模型选择器
空态与输入框 MUST 展示当前模型名（只读徽标）。

#### Scenario: 展示当前模型
- **WHEN** 打开应用或切换会话
- **THEN** 系统 MUST 显示 `ModelSettings.model` 的当前值

### Requirement: 命令菜单
系统 MUST 移除顶栏独立的「交互式 / 目标」切换；在输入框键入 `/` MUST 弹出命令菜单，含模式选择与相关技能选择；技能项 MUST 显示名称与描述，且键入 `/` 后的输入文本 MUST 实时过滤选项。

#### Scenario: 键入斜杠打开菜单
- **WHEN** 用户在输入框键首键入 `/`
- **THEN** 系统 MUST 弹出命令菜单，展示 交互式/目标 模式项与本地技能列表（每项含名称与描述）

#### Scenario: 输入过滤
- **WHEN** 键入 `/` 后用户继续输入文字
- **THEN** 系统 MUST 按该文字实时过滤模式与技能项（匹配名称/描述/id，技能项保留名称与描述展示），无命中时显示「无匹配」

#### Scenario: 选择模式
- **WHEN** 用户在菜单选择「目标」模式
- **THEN** 系统 MUST 将当前会话模式设为目标

#### Scenario: 选择技能
- **WHEN** 用户在菜单选择一个技能
- **THEN** 系统 MUST 将技能引用写入输入草稿，发送后 Agent 按该技能执行（复用技能匹配注入）
